# 架构图

系统分层、模块边界和静态依赖使用本族。只表达结构，不暗示调用先后；有消息顺序时改用 `sequenceDiagram`，强调跨角色责任时用 `swimlane`。

## layers

原生 `layers` 每层最多 6 组、每组最多 30 项，最多 8 层；层名和能力项宽度受限（层名最大 160px、能力项最大 208px），过宽会报错。每层写 `- 层名 | 说明`，其下用 `- 分组: 能力项, 能力项`；也可用 `- 分类 > 能力项, 能力项`。分组可标 `{db}` 或 `{ext}`；能力项前缀 `+`、`~`、`=` 分别表示新增、改造、复用。顶层不能混合层与分组模式，能力项不能脱离所属层；名称过宽、语法错误或超限会报错，应修正结构而非删除事实。

## blocks

原生 `blocks` 画一页总览图：虚线分组里放卡片或能力项，分组和卡片之间画关系，并可附图例。用空格缩进表示包含：

| 行 | 含义 |
|---|---|
| `row [权重]` / `col [权重]` | 不画框；子项从左到右 / 从上到下排列 |
| `grid N` | 不画框；N 列（1–12），按行填充，各列等宽，每行与最高的格子等高 |
| `box [权重] 标题 [{属性}] [: 能力项, 能力项]` | 虚线分组；子项横向排列，或直接列出能力项 |
| `card 标题 [{属性}]` | 卡片；其下每个缩进行是一行说明 |
| `note 文字` | 12px 说明文字，如列标题、脚注；不能作关系端点 |
| `legend` | 图例；其下每行写 `键: 含义` |

- 属性写在 `box` / `card` 行尾的 `{…}` 中，用逗号或空格分隔：样式词 `accent`、`new`、`info`、`ok`、`warn`、`danger`、`ext` 至多一个；`db`（仅分组，画成圆柱，可与样式词同用）；`#01` 形式的徽章（1–4 个字母、数字、`.` 或 `-`）；`@id` 引用名（全图唯一）；`"标签"`（仅卡片，最多 12 字）。颜色由主题决定：未加样式的卡片是无边框底块，加样式的卡片带对应颜色的边框，`ext` 画虚线。
- 关系顶格书写：`A -> B: 标签` 普通关系，`A => B` 主流程（强调线），`A ~> B` 异步或回流（虚线）。端点是分组或卡片，先按 `@id`、再按完整标题解析，必须唯一；标题重复或含 `:`、`->`、`=>`、`~>` 时，给目标加 `{@id}`。关系不能连到能力项或 `note`，也不能自连。
- 图例键为上述样式词、`default`（无样式卡片）、`db` 和 `->`、`=>`、`~>`，各出现一次；图例画出与图中一致的色块或线型。
- 关系走横平竖直的路径，绕开卡片、分组边框和标题，需要时自动加宽间隙，不改变作者给定的行列。仍找不到通道时报错，按提示减少共用同一通道的关系或调整组合。
- 上限：嵌套 8 层，分组与卡片合计 400 个，能力项 1000 个，关系 200 条；关系标签最多 24 字、2 行，卡片标题最多 2 行、说明最多 8 行，分组标题最多 3 行。分组与卡片超过 60 个，或自然宽度超过显示宽度 2 倍时，照常渲染并在图内横向滚动，同时提示拆成总图和分图。
- 能力项写法继续有效：`box 名称: 能力项, 能力项` 或在 box 下缩进列出，能力项可带 `[icon:名称]` 图标和 `+`（新增）、`~`（改造）、`=`（复用）前缀。同一个 box 里能力项和结构行不能混用；以 `card `、`note `、`grid N` 开头或恰为 `legend` 的缩进行按结构行解析。

```blocks
---
title: 每周复盘：问题怎么变成补丁
---
row
  box 输入
    col
      card 会话记录
        所有仓库的会话
      card 上期记录 {@last}
        待验证的改动
  box 复盘循环 {accent}
    grid 2
      card 收集数据 {accent #01}
        脚本跑指标
      card 找失败点 {accent #02}
        介入、无效震荡
      card 落地验证 {accent #04}
        回放题重放
      card 诊断选药 {accent #03}
        动态补丁优先
  col
    box 产出 {ok}
      col
        card 前置检查脚本 {ok}
        card 拦截钩子 {ok}
    legend
      accent: 循环步骤
      ok: 沉淀资产
      =>: 主流程
会话记录 => 收集数据
收集数据 => 找失败点
找失败点 => 诊断选药
诊断选药 => 落地验证
诊断选药 -> 产出: 沉淀
落地验证 ~> last: 下周回填
```

超出上限或一张图讲不清时，先拆成总图和分图；确实需要内置图族表达不了的机制示意时，按[手写 SVG](../guides/custom-svg.md) 绘制。

## C4Context

用 `Person`、`Person_Ext`、`System`、`System_Ext` 表达人员与系统，用 `Enterprise_Boundary` 等边界宏分组。

五种 C4 图共用 `Rel`、`BiRel`、`Rel_Back`、`RelIndex` 及方向关系宏（如 `Rel_L` / `Rel_Left`）。支持[通用样式、链接和标签图标](mermaid.md)；宏自带的 `sprite`、`tags`、`link` 等外观属性不应用并告警。`c4.c4ShapeInRow` / `c4.c4BoundaryInRow` 调整每行元素或边界数。未知语句、未声明的端点或未闭合的边界报错。

## C4Container

用 `Container`、`ContainerDb`、`ContainerQueue` 和 `System_Boundary` 表达容器及依赖。样式、配置、关系和诊断见 [C4 通用规则](#c4context)。

## C4Component

用 `Component` 与 `System_Boundary` / `Container_Boundary` 表达组件及边界，不表达执行顺序。样式、配置、关系和诊断见 [C4 通用规则](#c4context)。

## C4Dynamic

表达元素间有方向的交互。按声明顺序编号，不采用 `RelIndex` 给出的编号。样式、配置、关系和诊断见 [C4 通用规则](#c4context)。

## C4Deployment

用 `Deployment_Node`、`Node_L` 或 `Node_R` 声明部署节点，可嵌套并包含其他 C4 元素。样式、配置、关系和诊断见 [C4 通用规则](#c4context)。

## architecture-beta

Mermaid 12.3.0 只解析 `architecture-beta`，要在其他 Mermaid 环境中使用时写这个关键字；KChart 也接受 `architecture`。`group id(icon)[名称]` 声明分组（可嵌套，`in 父组`），`service id(icon)[名称] in 组` 声明服务，`junction id` 声明连线交汇点（画成点，不画成框），`a:R --> L:b` 按端口 `L`/`R`/`T`/`B` 连线，`{group}` 后缀可连到分组边界。内置图标 `cloud`、`database`、`disk`、`internet`、`server`；`logos:…`、`mdi:…` 等图标名按内置图标或宿主注册的图标解析，解析不到时省略图标并告警。`align row` / `align column` 可指定对齐；`architecture.padding`、`iconSize`、`fontSize` 调整间距与尺寸（均在 `config.architecture` 下）。支持通用样式与安全链接。端点未声明或分组端口未跨越所属分组边界时会报错。

## block

也接受 `block-beta`。块图按作者给定的网格排布：`columns N` 或 `columns auto` 设列数，`id["名称"]` 等方括号写法声明块及形状，`id:2` 跨列，`space` / `space:N` 留空位，`block:id … end` 嵌套分组，`id<["标签"]>(right)` 画块状箭头，`A --> B` / `A -- 标签 --> B` 画连线。列数、顺序和跨列按源码落位；窄屏时滚动，不重排网格。`block.padding` 调整嵌套块内边距。嵌套分组画成虚线框，标题在左上角；连线走横平竖直的路径，绕开块、分组边框和标题，需要时自动加宽间隙，但不改变列数、顺序和跨列。支持通用样式、链接和标签图标；仍找不到走线通道时报错，可用 `space` 留出位置。要画带徽章、说明和图例的总览图时，用原生 [`blocks`](#blocks)。

## wardley-beta

Wardley 地图用 `anchor 名称 [可见度, 演化]` 放置锚点，用 `component 名称 [可见度, 演化]` 放置组件。可见度沿纵轴从下往上增加，演化沿横轴从左往右增加。坐标须带小数点：0–1（含 `1.0`）按比例解释，大于 1 且不超过 100 按百分数解释。复杂名称可用双引号；组件可附 `label [dx, dy]`、`(build)` / `(buy)` / `(outsource)` / `(market)` 和 `inertia`。

- `A -> B` 表示依赖，`A -.-> B` 画虚线；`A +> B`、`A +< B`、`A +<> B` 分别画正向、反向、双向箭头。行尾 `; 标签` 或 `A +'标签'> B` 可标文字。`evolve A 0.8` 表示向目标演化值移动。依赖保持在两端的直线上；经过其他组件时留空，重合部分共用一段线。显式 `label [dx, dy]` 不自动移位，压线时加底色保证文字可读。
- `evolution 阶段 -> 阶段` 自定义阶段，`阶段@0.5 / 副标题` 可标该阶段的右边界和副标题。边界不齐、未递增或未到 100% 时回退到等宽阶段并提示。`pipeline 父组件 { … }` 内逐行写 `component 名称 [演化]`，子组件继承父组件的可见度。
- `note "文本" [可见度, 演化]` 添加备注；`annotation 1,[可见度, 演化] "文本"` 画编号标记，`annotations [可见度, 演化]` 指定图例首选位置。`accelerator "名称" [可见度, 演化]` 和 `deaccelerator "名称" [可见度, 演化]` 画方向相反的作用力箭头。
- 支持正文 `title` 和共享无障碍字段 `accTitle` / `accDescr`。前言区或初始化指令可设 `config.wardley.width`、`config.wardley.height`；正文 `size [宽, 高]` 优先。画布必要时为标签留出额外空间，窄屏横向滚动。标题和显示标签支持常见实体、换行和 `fa:fa-…` 图标；未知图标只提示，不画占位。`showGrid` 不生效并给出配置警告。无效坐标、未闭合的管道或无效引用会报错；不接受通用样式或点击语句。

阅读文档须提供图题；优先使用前言 `title`，不依赖图框外的说明。
