# 从材料到页面

把 Markdown、纯文本、聊天或会议记录、JSON、CSV、日志或零散笔记做成 HTML 之前读本页。本页决定内容怎么组织、每段信息用什么组件；命令和组件写法见[文档流程](../artifacts/doc.md)和[文档组件](../artifacts/doc-components.md)。

## 先定读者要做什么

动手前写下：谁读，读完要做什么，最先要知道什么。这决定产物、类型和开头放什么：

| 读者读完要 | 产物 | 开头放 |
|---|---|---|
| 拍板或批准 | 文档 `--type one-pager` 或 `report` | 文首摘要：结论和需要的决定 |
| 评审方案 | 文档 `--type tech-spec` | 结论、范围和方案要点 |
| 照着操作 | 文档 `--type doc` | 前提，然后是步骤 |
| 理解系统或流程 | 文档 `--type explainer` | 一张总图 |
| 核对数字和口径 | 数据报表 | KPI |
| 体验交互 | 界面稿 | 第一个屏幕 |

材料的顺序是作者写下它的顺序，常常是先背景后结论，或按时间记流水账；读者则是带着任务找信息。按读者的顺序重排章节，但不改动事实。

## 按信息关系选组件

先判断每段材料是什么，再选表达方式。组件只在比段落更清楚时使用。

| 这段信息是 | 用 |
|---|---|
| 结论、建议、需要谁决定 | 文首摘要 `.summary` |
| 有先后、要照着做 | `ol.steps` |
| 按日期发生或计划 | `ol.timeline` |
| 几个对象在同一组属性上对照 | 表格 |
| 3–6 个关键数字 | `.stats` |
| 数量的变化、比较或构成 | KChart 图，按 SKILL.md「按读者要看什么选图」选图型 |
| 组件、调用、状态或依赖关系 | 结构图 |
| 前提、限制、风险、例外 | 提示条，按语义取 `data-k` |
| 推导过程、原始数据、长清单、备选方案 | `details.fold` 或文末附录 |
| 字段、参数、命令、报文 | 表格或代码块，原文照录 |
| 论证和解释 | 段落 |

同一信息只出现一次：摘要写结论，正文写依据，不要逐句重复。一节只回答一个问题，混着几个问题就拆开。标题要让读者只看目录就能找到要看的部分。

## 按来源处理

- **Markdown**：保留作者的章节，修正标题层级（只有一个一级标题，不跳级）。「注意：」「风险：」开头的段落改成 `> [!WARNING]` 等提示条，编号操作改成步骤，带日期的条目改成时间线。用 `doc build` 生成，以后改 Markdown 再重新生成。
- **纯文本、聊天和会议记录**：按主题分节，不按发言顺序。决定、待办（负责人、期限）和未决问题各列一张表；引语保留原话，并注明说话人。材料里没写负责人或期限时写「未定」，不要补。
- **JSON**：配置对象写成字段表（字段、类型、含义、示例值）；记录数组写成表格；层级用 `tree` 或脑图；带时间戳的事件写成时间线。需要原文时放进代码块，长内容折叠。
- **CSV**：读者要核对数字和口径时，做数据报表。如果只是在文档里支撑一个论点，用 KChart 图并在图题写结论；如果图下已有可展开的「图表数据」，就不再抄一张表。
- **操作说明和流程**：线性步骤用 `ol.steps`，有分支用 `flowchart`，多个角色交接用 `swimlane`。
- **日志和报错**：原文放进代码块，不改写；正文概括规律、影响范围和发生时间。

## 不增删事实

- 不添加材料里没有的数字、日期、人名、原因或结论。为了版面完整而缺的内容，比如凑不满第四张指标卡，就删掉这一项或整个组件。
- 读者需要但材料缺失的信息，写成待确认项，说明缺什么、谁能提供。
- 改写措辞时不改变程度：「可能」不写成「会」，「部分」不写成「全部」。
- 注明来源。材料只有一两份时，在文首或文末说明一次；各部分来自不同材料时，再在图的 `source` 或段落后就近标注。

## 交付前检查

1. 对照原材料逐节核对：结论、数字、限制和待决问题都在，没有新增事实。
2. 运行 `htmlview audit` 和 `htmlview check`，再打开 `htmlview shot` 的首屏截图，确认桌面和手机首屏都能看到标题和结论。
3. 检查整页节奏：`htmlview export file.html --format png --out page.png` 生成整页长图，看有没有大段文字墙、堆在一起的组件、空节和过长的表。
4. 交付 PDF 时，按[显示与导出](check-export.md)检查分页。
