# 界面设计

画界面稿前确定版式和配色、手写组件清单里没有的部分，或觉得稿子像模板拼凑时读本页。组件和变量名见[组件索引](../artifacts/ui-components.md)，数据看板见[看板设计](dashboard.md)。

## 先定任务和状态

- 每个屏幕只服务一个主要任务，标题直接说出它。主操作只有一个，用实心主色按钮；次要操作用 `outline` 或 `ghost`；破坏性操作用 `danger`，并要求二次确认。
- 按用户路径列屏幕，路径之外的页面不画。每个屏幕想清楚有数据、空、加载、出错四种状态，提交类操作还要有成功反馈；用 `data-states` 画出关键的几种。
- 数据用可信的虚构样例：人名、商品名、金额和时间用真实长度，并标明虚构，不用 lorem 或「标题一」。

## 版式骨架

| 设备 | 骨架 | 要点 |
|---|---|---|
| 手机 | `app-bar`、单列内容、最多 5 项的 `tab-bar` | 主操作放在拇指够得到的底部；次要选择用 `sheet`；首屏露出主要内容和主操作 |
| 桌面 | `side-nav`、`top-bar`、内容区 | 列表到详情用左右两栏；工作台用三栏，列表约 280–320px，主区自适应，侧栏约 280–360px；表格页把筛选放在表格上方 |
| 响应式 | 与桌面同一套屏幕，不用 `app-bar` | 窄屏把多栏收成单列，用 `tabs` 或 `seg` 切换栏位，不为手机另画一套屏幕 |

## 字号与层级

- 只用 `--ui-fs-*` 阶梯：页面标题 20–24，分区标题 16，正文 14，说明和时间 12–14。一屏最多三级字号，层级靠字号、字重和文字深浅区分，不靠彩色。
- 标题用 `--fg-1`，正文 `--fg-2`，说明 `--fg-3`；`--fg-4` 只用于占位和禁用。数字列右对齐。
- 一行中文不超过约 40 字；长段落改成列表或键值对。

## 间距与密度

- 间距只取 `--ui-sp-*`：组内 8，组间 16–24，分区之间 24–32，卡片内边距 16。同类元素之间的间距处处相同。
- 手机上的可点区域至少 44×44px；桌面控件高度用 `--control-h`。数据密集的后台用 `--density compact`，消费类界面用默认密度。
- 内容对齐到同一条左边线。卡片里的图和文字共用卡片的内边距，不再额外缩进。

## 颜色

- 以中性色为主，用 `--bg`、`--surface`、`--surface-2` 和 `--line` 拉开层次。
- 品牌色只给主操作、当前项、链接、选中态和需要突出的单个数字。选中项用 `--accent-soft` 作底、`--accent-text` 作字。一屏的实心主色块不超过一处。
- 状态色只表示状态，并配上文字或图标，不只靠颜色区分。线框稿不用红色，错误和风险用文字和图标说明。
- 不用渐变、霓虹色、彩色阴影或大面积纯色块装饰。
- 深色下 `--surface` 与 `--bg` 相同。卡片、对方消息和输入区用 `--surface-2` 或 `--line-strong` 边框分层，不靠阴影。

## 形状、阴影与动效

- 圆角取设计参数：小件 `--ui-r-sm`，卡片 `--ui-r-md`，弹层 `--ui-r-lg`。同一屏不混用别的圆角。
- 卡片默认用边框。`--shadow-1` 只给浮起的小元素，`--shadow-2` 只给弹层。
- 动效只用于状态变化的过渡，时长约 200ms，不做循环的装饰动画。

## 常见界面

- **列表与详情**：列表行只放识别信息和一两个关键字段，其余放进详情；行内操作收进「更多」菜单。
- **表单**：标签在上，单列排列；标注必填项，错误写在字段下方；提交按钮放在表单末尾，长表单用 `stepper` 分步。
- **设置**：按主题分组，每组一个标题，下面是开关或选择项；即时生效的项不再放「保存」按钮。
- **聊天与客服**：对方消息靠左、自己的靠右，按时间分组；系统消息居中，字号小一级；输入区固定在底部，快捷回复放在输入框上方。
- **媒体播放**：封面或画面占位最大，主播放键最醒目，其余控制用图标按钮；进度条显示已播时长和总时长。
- **电商与内容**：商品图占位、价格和主按钮（加购或购买）在一屏内可见；规格、评价等次要信息往下排。
- **审批与工单**：顶部放当前状态和下一步操作；处理记录用时间线，全稿统一按时间正序或倒序。

## 交付前自查

- 三秒内能看出这屏做什么、主操作在哪。
- 实心主色按钮只有一个；颜色都来自变量；状态都有文字。
- 字号不超过三级，间距落在 4px 阶梯上，左边线对齐。
- 关键的空、加载、出错状态已画出；可点元素都有声明式交互或 `data-action`。
- 浅色和深色都看过，深色下各层仍能分清。
- 手机宽度下没有横向滚动、文字截断或被遮挡的按钮。
