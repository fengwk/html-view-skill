### How to read these figures

The current period is October 2026 (UTC, a complete month). Commits and official releases come from the public GitHub REST API for [kubernetes/kubernetes](https://github.com/kubernetes/kubernetes), fetched at 2026-11-24T17:22Z. The repository is licensed under Apache-2.0.

October had {{monthly.commits.value}} commits, {{monthly.commits.mom_text}}, the highest month in the complete observation window from December 2025 through October 2026. September, the month-over-month baseline, had {{monthly.commits.mom_baseline}} commits. August was sharply lower than the months on either side; this dataset does not give a reason.

The same month had {{monthly.official_releases.value}} official releases, {{monthly.official_releases.mom_text}}, all patches: v1.37.2, v1.36.6, v1.35.10, and v1.34.13, each published on 2026-10-28. The most recent minor release in the window is v1.37.0 on 2026-08-26. January 2026 has zero official release tags; the chart shows 0, not a missing value.

Stars ({{snapshot.stars.value}}) and open issues including PRs ({{snapshot.open_issues_and_prs.value}}) are a point-in-time public snapshot at fetch time. They are not October totals and have no month-over-month comparison. GitHub's `open_issues_count` includes open pull requests.
